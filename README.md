Bu depo, Türkiye Cumhuriyeti sınırları içinde (ve balkon taşması durumunda komşu ilçede) meydana gelen ev içi krizleri, **terlik diplomasisi** yoluyla uluslararası nota formatına çevirir.

## Misyon

Komşunun gece 02:14'te süpürge çekmesi bir sınır ihlalidir. Kaybolan kumanda bir rehindir. Buzdolabı kapağının 11 saniye açık kalması iklim anlaşmasının ihlalidir. Protokol, bu olayları ciddiye alır. Fazla ciddiye alır. Ciddiyeti o kadar abartır ki ciddiyet kızarır.

## Kurulum

```bash
git clone https://github.com/Tentivory/terlik-disisleri-protokolu.git
cd terlik-disisleri-protokolu
python3 terlik_protokolu.py --olay "kumanda koltuk arasında rehin"
```

Bağımlılık yoktur. Sadece Python 3 ve bir çift terlik. Terlik yazılıma dahil değildir. Dahil olsaydı Git LFS ağlardı.

## Kullanım

```bash
python3 terlik_protokolu.py --olay "üst kat süpürge operasyonu" --seviye 4
python3 terlik_protokolu.py --demo
python3 terlik_protokolu.py --olay "test" --arsiv
```

`--arsiv` bayrağı protokolün bodrum katını açar. Bodrum kat haritada yoktur. Harita da yoktur.
